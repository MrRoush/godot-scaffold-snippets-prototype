# Contribution Guide

## Standards
- Target Godot 4.7+ API.
- Keep prototype lightweight and data-driven.
- Prefer plain language in UI text.

## Commit Style
Use prefixes:
- `feat:` new feature
- `fix:` bug fix
- `docs:` documentation
- `refactor:` internal improvements

## Add a New Snippet
1. Open relevant pack in `snippets/`.
2. Add snippet entry with unique `id`.
3. Include `title`, `code`, and `comments`.
4. Keep code idiomatic GDScript and beginner-readable.

## Accessibility Checklist (minimum)
- Avoid jargon in labels.
- Keep lines short and scannable.
- Never rely on color alone to convey meaning.
