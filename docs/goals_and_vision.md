# Vision and Goals Alignment

## Course Context
Game Development course using Godot 4.7 with mixed coding readiness.

## Primary Student Problem
Many students get blocked by syntax and error noise before they can express game logic.

## Goals (from classroom brief)
1. Lightweight approach to simplify coding.
2. Easy to read for ELL and students with reading difficulties.
3. Reduce panic from raw errors via user-friendly messages.
4. Mirror GDScript structure to support transfer.

## Prototype Decisions
- Use real GDScript snippets, not a custom language.
- Add progressive scaffolding levels.
- Provide plain-language error explanations.
- Start with beginner genres (platformer, top-down).

## Success Criteria for Next Iteration
- Student can build basic movement in < 15 minutes.
- Student can fix at least 2 common syntax issues with helper panel.
- Student can explain one generated script block in their own words.
